Rivet’s Junkyard Flight

A compact arcade game about launching a raccoon through an extremely unsafe junkyard.

Game design · physics · procedural systems · test automation

4launch machines
10upgrade tracks
2test modes

The experiment

This project tests a different kind of game feel: a two-tap launch, a few meaningful choices in the air, exaggerated collisions, and an immediate “one more run” loop.

The challenge was to make a small prototype feel authored while much of the course and presentation is assembled procedurally.

What I built

  • Aim, power, launch, flight, summary, garage, and retry states
  • Tuned bounce, momentum retention, recoil shots, and a one-use rocket action
  • Four launch machines, randomized courses, persistent coins, distance rewards, and ten upgrade tracks
  • Procedural squash and stretch, trails, impacts, camera shake, synthesized sound, and a responsive landscape UI

Key decisions

Constrain the midair choice

A few recoil shots make each input count and create a clean upgrade path without turning flight into continuous steering.

Fresh layout, stable rules

The course changes each run, but the interaction language stays consistent enough for players to learn.

Test the generated experience

EditMode tests cover progression and safety invariants; a PlayMode smoke test confirms that the real loop starts. The standalone macOS build was also launched and inspected.

What I learned

Small games benefit from deliberate constraints. A narrow input vocabulary, readable economy, and fast retries gave this prototype more character than another layer of controls would have.
